What this build does
- Enumerates EVERY EGL config (eglGetConfigs), R/G/B/A all four, WINDOW / PBUFFER / RECORDABLE separately, eglGetError after each call.
- Tries real offscreen paths if PBUFFER is missing on the recordable WINDOW config: PBUFFER, then EGL_KHR_surfaceless_context, then a dummy SurfaceTexture window. Uses the first that actually makeCurrent's.
- Does not silently use an 8-bit surface for HDR. Does not skip the gradation check.
- If EGL never becomes current, colour / tags / bitstream / metadata / gradation are INCONCLUSIVE: «لم تُنفّذ بسبب فشل تهيئة EGL» — not FAIL from a fake measurement.
- Lists the HEVC encoder's declared colorFormats, including COLOR_FormatYUVP010 (54). That is a declaration check only; a YUV P010 encode path is NOT implemented.
